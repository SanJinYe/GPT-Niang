# 边缘与角落自动姿势

内置龙娘在普通拖动结束时，按角色图像边界与窗口边框的距离选择姿势。触发距离为 24 个逻辑像素，随 DPI 缩放；下角同时命中两条边时优先选择角落图。

| 位置 | 行为 |
|---|---|
| 左右侧边 | 双手抓握线贴住对应竖框，头向外探出 |
| 侧边贴近屏幕边缘 | 使用反方向的专用姿势向内探，保证可见 |
| 左右下角 | 对应抢镜脸贴齐下边与侧边 |
| 左右上角 | 分别重绘的抢镜脸，从上角探下；发饰按头部朝向保留角色侧别 |
| 上方中间 | 倒挂姿势，头发依重力下垂；气泡显示在角色下方 |
| 拖离边缘 | 恢复原来的自由形象 |

左右素材分别绘制，不镜像发饰。自定义导入角色不应用这套龙娘姿势。吸附模式和抓握高度随设置保存；通过“恢复右下角位置”可回到右下角姿势。

三类形象按脸部大小进行光学校准，而不是统一 PNG 外框。`Get-WidgetPoseScale` 以原版为基准，校准侧边全身范围较多、角落脸部特写较大的差异；测试使用眼距占原图长边的参考测量值，检查各 DPI／缩放下的显示眼距差异。角落版保留睁眼张嘴表情，但肤色与淡紫色眼睛／瞳孔画法统一到原版及侧边版。换回自由形象时重新对齐拖动起点，避免尺寸变化导致跳动。

按最新反馈，取消角落额外放大，所有姿势统一按眼距校准到原版面部大小。拖动四帧按 0.259／0.167 的比例放大，避免全身图套用半身图外框导致脸缩小。

吸附状态下开启音乐律动时，角色固定在边框上跟拍，不沿窗口游走；灯效开关仍有效。侧边模式做横向探缩与轻微点头，整条抓握线保持固定；下角模式做横纵向组合的伸缩回弹，角点及两条接边保持固定。左侧反向布局单独换算律动支点，避免发饰方向修正后手部漂移。拖动吸附中的角色会进入普通拖动，释放后重新判断吸附位置。自由状态的原有律动、投掷和左右移动开关保持原行为。

左右下角首次吸附时，从角外斜向探入：前 240 毫秒快速进入并轻微越过最终位置，380 毫秒时归位。切换到同一姿势或普通位置更新不会反复播放；拖离角落、换形象会取消并清理动画。节奏参考南小鸟抢镜脸动图与 [BB 素材合集页面](https://www.bilibili.com/video/BV1RP4y147Zr/)，不是逐帧复刻。

四种吸附姿势均复用原点击反馈：按下时横向 1.05、纵向 0.88，松开恢复 1，动画时长 220 毫秒并带回弹。伸缩中心落在侧边抓握线或下角锚点。入场、单击和音乐律动使用分开的变换，不相互覆盖，也不带着额度气泡一起移位。

代码入口：`runtime/dock-poses.ps1` 负责选图与定位；`widget.ps1` 接入拖动和设置；`runtime/host-follow.ps1` 仅在侧边姿势时允许绘制到窗框外，并继续按屏幕工作区裁切；`runtime/music-visual.cs` 支持固定锚点的律动。

验证脚本：`tests/dock-poses.test.ps1`（缩放、DPI、抓握线、角落优先及自定义角色）、`tests/dock-native.test.ps1`（真实窗口裁切）以及现有拖动与音乐测试。`dock-poses.test.ps1 -OutputDirectory <目录>` 可导出四种姿势的窗口位置预览。

`tests/dock-animation.test.ps1` 检查四种姿势的伸缩锚点、两侧入场方向、归位、单次触发及中断清理，可用 `pwsh.exe -NoProfile -STA -File` 执行。

`tests/dock-rhythm.test.ps1` 检查侧边与下角各自的跟拍变形、接边固定和静止恢复；`music-visual.test.ps1` 另检查真实 WPF 正向／反向布局的支点及固定窗口位置。

## 律动装饰与顶部行为

律动统一使用固定的 100 BPM，即每 0.6 秒一轮，不随歌曲 BPM 改变；各姿势的形变、摇摆及灯球摆动幅度统一降到此前的 45%。点击回弹与吸附入场动画不受此设置影响。跟随网易云时仍由播放／暂停状态控制启停，手动律动开启后则持续按固定周期运行。

- 侧边：白色头戴式耳机与墨镜，随角色的探缩和点头一起变形。
- 四个角的抢镜脸：墨镜与浮动音符。
- 上方中间：双手扒住上沿、戴墨镜；以整条上沿为固定线做水平斜切，形成左右交替的平行四边形变形，不旋转整张图片。
- 下方原姿势：保留原来的音响与墨镜。

饰品是临时绘制层，不写入角色图片；关闭律动后清除。各姿势分别标注眼睛位置与方向，按实际显示尺寸及角色变换定位。纵长图按实际绘制宽度计算，避免留白被重复计入而使墨镜偏移。

四角的音符使用独立的窗口坐标图层，以 13 个逻辑像素为基准尺寸漂浮，不跟随角色大小、点击伸缩或律动形变缩放。律动拖动在边框释放时会先完成吸附再恢复当前律动；自由区域释放仍保留投掷，普通吸附姿势拖动也会保留手动律动的开启状态。

顶部使用独立的上沿定位；窗口只改变高度时，挂件不会随下沿移动。顶部气泡需要额外的透明画布空间，切回其他位置后恢复原尺寸。上角也有从上方探入的入场动画及固定锚点的点击回弹。

`tests/dock-accessories.test.ps1` 检查七种姿势的临时装饰层和实际显示支点，设定 `GPT_NIANG_PREVIEW_DIR` 可导出预览。
