# 鼠标与触摸板点击

挂件统一接收 Windows 提供的左键按下、移动和松开事件，不通过是否插入鼠标切换输入模式，也不接管触摸板的多指手势。轻点、按压点击和系统配置的轻点拖移走同一条处理路径。

旧实现按下超过 200 毫秒就设置 `moved=true`，松开时也会按处理时钟再次判定。因此没有移动的慢点击、延迟送达或处理的松开事件也会吞掉额度与台词轮播。这是应用手势判定问题；尚未采集用户触摸板事件，不能把具体驱动的全部异常都归因于此。

当前规则：

- 按下立即提供 Q 弹反馈，500 毫秒后仍可显示提起动画。
- 长按提起只预览，位移达到20 DIP 阈值（由 6、12 DIP 逐步扩大，以容纳触摸板按压滑动）才确认拖动；阈值随显示 DPI 转换为屏幕像素。
- 未达到阈值就松开，恢复原位置和形象并执行一次点击，轮播额度或台词。
- 一旦确认拖动，即使回到原点也不点击；保留吸附、松开结束吸附豁免及律动恢复逻辑。
- 失去捕获或取消操作不触发点击。触摸板和鼠标共用系统指针，交替使用不需要开关。

`tests/live-docking.test.ps1` 覆盖延迟松开、长按预览、抖动、松开时首次越过阈值、取消和已有吸附流程。模拟事件不能替代不同触摸板驱动的实机测试。如果系统未发送左键事件，该逻辑无法生成缺失的点击。

Windows 输入语义参考：[Touchpad interactions](https://learn.microsoft.com/en-us/windows/apps/develop/input/touchpad-interactions)。
